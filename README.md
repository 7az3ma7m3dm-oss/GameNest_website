# GameNest Shop — Phone Upload Version

Upload ONLY these website files to the ROOT of your GitHub repository:

- index.html
- style.css
- gamenest-logo.png

There is intentionally NO script.js.

The exact GameNest logo is included as `gamenest-logo.png` and is ALSO embedded directly inside `index.html`, so the visible website logo does not depend on a folder path.

For GitHub Pages:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
